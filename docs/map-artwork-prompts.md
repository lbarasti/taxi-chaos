# Gritty artwork prompts

Generated with the built-in image-generation tool. The user supplied a top-down urban scene as a style reference. Each PNG was generated separately with transparency, then its near-transparent export margin was trimmed and the sprite resized for the game (256 px roofs, 192 px tree). Source artwork is preserved in the generation outputs. No API/CLI fallback was used.

## shop-tar.png

Use case: stylized-concept. Asset type: actual transparent PNG building sprite for a top-down driving game. The input image is STYLE REFERENCE ONLY: its gritty muted urban materials, visual density, and true overhead architecture. Generate ONE isolated square 10m by 10m shop rooftop, straight orthographic overhead, aligned with image axes. Occupy 96% of a square canvas with the complete building footprint, centred; leave only a thin transparent margin. No ground, pavement, street, people, vehicles, text or cast shadow outside the footprint. Flat ambient diffuse light; convincing local grime and material shading, but no dramatic illumination. Southern/bottom edge has a narrow faded striped shop awning; keep it inside the square. Rich painterly realistic game art, crisp at small size, dirty charcoal, desaturated concrete, moss, oxidised metal; avoid polished toy-like vector look. All props stay inside the building footprint. This building has a patched near-black bitumen flat roof, irregular grey repairs, damp stains and drain channels. One large battered twin-fan HVAC unit in the upper-left, old pale skylight lower-right, tangled pipes, a few windblown scraps. Faded burgundy and dirty-cream striped bottom awning. Strong asymmetry and broad readable patches.
