# Landmark artwork prompts

Created with the built-in image-generation tool. The user's four-landmark concept sheet was reference image 1; their earlier gritty city scene was style reference image 2. Each image was generated separately with transparency. Preparation trims the near-transparent export fringe (alpha threshold 16 for bounds only), contains the art within 480 × 480 pixels without changing its aspect ratio, and centres it on a transparent 512 × 512 canvas. Original generation outputs are preserved. No CLI/API fallback was used.
